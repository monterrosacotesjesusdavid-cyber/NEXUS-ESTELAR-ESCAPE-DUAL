# Nexus Estelar: Escape Dual

Juego cooperativo 2D online para 2 jugadores (PATO y GATO).

## Personalizar
- `public/memorias.json`: tus 5 recuerdos reales (frases, fechas, momentos). Se desbloquean en el observatorio.
- `public/assets/musica/observatorio.mp3`: música del observatorio (opcional).
- `public/assets/musica/final.mp3`: canción del final (opcional).

## Subir a GitHub y Railway
1. Sube TODOS los archivos respetando las carpetas (menos `node_modules`).
2. Railway → New Project → Deploy from GitHub repo → Settings → Networking → Generate Domain.
3. Los dos abren el link, escriben el mismo código de sala y juegan.

## Controles
Mover: flechas o A D · Saltar: Espacio · E: acción · R: enfriar (Acto 3) · T: ir con tu pareja · Q: intercambiar posiciones · V: visión compartida · 1 2 3: escudos (Acto 5). En celular aparecen botones en pantalla.
